# Распознавание лиц с использованием PyTorch и Streamlit

Этот проект представляет собой приложение для распознавания лиц, разработанное с использованием PyTorch и Streamlit.  Он позволяет обучать модель распознавания лиц на основе набора изображений и использовать эту модель для распознавания лиц на новых изображениях.

## Установка

1.  **Клонируйте репозиторий:**
```bash
    git clone <ваш_репозиторий>
    cd <имя_папки_репозитория>
```
2. Создайте виртуальное окружение (рекомендуется):
```bash
  python -m venv .venv
```
  •  macOS/Linux:
```bash
    source .venv/bin/activate
```

3. Установите зависимости:

  
```bash
  pip install -r requirements.txt
```

▌Структура проекта

•  app.py: Основной файл приложения Streamlit.
•  model.py: Файл, содержащий определение модели распознавания лиц и функции для ее обучения и сохранения.
•  utils.py: Файл, содержащий вспомогательные функции, такие как обнаружение и выравнивание лиц.
•  data/: Директория, содержащая наборы данных для обучения. Убедитесь, что фотографии для каждого человека находятся в отдельных папках внутри этой директории. Например:

  
```
data/
  └── lfw-deepfunneled/
    └── students/
      ├── person1/
      │  ├── image1.jpg
      │  ├── image2.jpg
      │  └── ...
      ├── person2/
      │  ├── image1.jpg
      │  ├── image2.jpg
      │  └── ...
      └── ...
```

•  models/: Директория для сохранения обученных моделей.

▌Использование

1. Запустите приложение Streamlit:

  
```bash
  streamlit run app.py
```

  Это откроет приложение в вашем браузере.

2. Обучите модель:

  •  Убедитесь, что в папке data лежат фотографии для обучения, организованные по папкам с именами людей.
  •  Нажмите кнопку "Обучить модель".

3. Распознайте лицо:

  •  Загрузите изображение с лицом через загрузчик файлов.
  •  Приложение попытается распознать лицо и отобразит результат.

▌Настройка

•  DATA_DIR в app.py: Укажите путь к вашей директории с данными для обучения.
•  MODEL_PATH в app.py: Укажите путь, где будет сохраняться обученная модель.
•  epochs в app.py: Измените количество эпох обучения для достижения лучших результатов.
•  batch_size в app.py: Настройте размер батча в соответствии с возможностями вашей GPU.
